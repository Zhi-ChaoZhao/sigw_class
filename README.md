A modified version of `GW_CLASS`: 
A comprehensive analysis of gravitational waves induced by non-Gaussian cosmological curvature perturbations. Our code calculates the energy-density fraction spectrum and the angular power spectrum, and these features have been integrated into gw_class. Additionally, the code can compute the correlation between SIGW and CMB. 


Used in arXiv: 2412.02500
